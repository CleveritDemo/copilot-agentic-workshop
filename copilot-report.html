📋 Nota Metodológica

  • Fuente de datos: GitHub Copilot Usage Metrics Reports API (v2026-03-10) y Billing Seats API.
  • Período analizado: 2026-05-05 al 2026-06-01 (últimos 30 días).
  • Tokens quemados: La API de GitHub Copilot no expone tokens de LLM por usuario. Las métricas disponibles son: sugerencias, aceptaciones, líneas y chats.
  • Actividad por usuario: El campo last_activity_at de cada seat es el proxy más preciso disponible. Las métricas de uso (sugerencias/chats) son agregadas a nivel organización, no desglosadas por usuario individual.
  • Tasa de aceptación: Principal KPI de efectividad. Un valor ≥ 30% se considera excelente en la industria.
  • Consolidación: El script descarga todos los download_links de reportes de organización y usuarios, y consolida los días en un único dataset.
  • Seguridad: El script ejecuta únicamente operaciones HTTP GET (solo lectura). No modifica configuración, licencias ni usuarios de la organización.
  • Estimación de consumo: Se calcula como (aceptaciones + chats) ÷ usuarios_activos. Esta es la alternativa viable más cercana para estimar consumo por usuario cuando no hay datos de tokens de LLM disponibles en la API.
